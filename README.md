# 🚗 JCars Logistics Sales & Logistics Analytics

## 📌 Project Overview

This project demonstrates an end-to-end Business Intelligence workflow using **PostgreSQL** and **Power BI** to analyze sales and logistics operations for **JCars Logistics**, a vehicle import and distribution company operating across Kenya.

The objective was to transform a raw flat dataset into an interactive management dashboard capable of supporting data-driven business decisions through meaningful KPIs, visualizations, and actionable insights.

---

## 🎯 Project Objectives

The project aimed to:

- Import a raw dataset into an Aiven PostgreSQL database.
- Clean and prepare the data for analysis.
- Connect PostgreSQL to Power BI.
- Create DAX measures and calculations.
- Build an interactive dashboard.
- Generate business insights and recommendations to support management decision-making. :contentReference[oaicite:0]{index=0}
